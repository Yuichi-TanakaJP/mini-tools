# Penguin Shooter stage-boss SVGs

These files are production-oriented concept assets for the planned ten-stage
version of Penguin Shooter. Each SVG uses a `240 x 180` viewBox and keeps the
main core near the center so it can share a predictable in-game hit area.

| Stage | File | Theme |
|---:|---|---|
| 1 | `stage-01-scrap-fortress.svg` | Scrap town fortress |
| 2 | `stage-02-verdant-citadel.svg` | Green kingdom citadel |
| 3 | `stage-03-frost-kraken.svg` | Frozen sea kraken machine |
| 4 | `stage-04-sand-sphinx.svg` | Desert ruins sphinx craft |
| 5 | `stage-05-tempest-airship.svg` | Cloud-city airship |
| 6 | `stage-06-lunar-golem.svg` | Lunar rock golem |
| 7 | `stage-07-volcano-fortress.svg` | Martian volcano fortress |
| 8 | `stage-08-clockwork-emperor.svg` | Clockwork machine emperor |
| 9 | `stage-09-gravity-eater.svg` | Black-hole gravity eater |
| 10 | `stage-10-world-rift.svg` | Living interdimensional rift |

Stages 1–9 use a readable mechanical vocabulary: body, central core, weapons,
and stage-specific armor. Stage 10 intentionally breaks that family. It has no
cockpit or conventional guns and instead uses an asymmetric eye, membranes,
crystals, and tendrils.

The SVG is presentation only. Collision shapes, damage zones, and animation
timing remain game-code responsibilities.
