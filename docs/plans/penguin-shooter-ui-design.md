# ペンギンシューター UI設計（10ステージ・武器拡張版）

## 目的

ゲーム中に「いま何ステージか」「次に何を目指すか」「どの武器を使っているか」「ボスがどれだけ残っているか」を、プレイを止めずに把握できるUIを設計する。

本書は実装前のUI設計であり、コンポーネント・CSS・配置の判断基準とする。

## 情報設計

ゲーム中の情報を3つのグループに分ける。

1. **Progress**: Stage、Small、救出進捗、ステージ名
2. **Combat**: Weapon、武器切替、ボム、ライフ、バリア
3. **Feedback**: スコア、コイン、コンボ、ボス名、HP、攻撃名

重要度は、ゲームプレイに直結するCombatを最上位、次にProgress、補助情報としてFeedbackとする。

## デスクトップ構成

```text
┌──────────────────────────────────────────────┐
│ Stage 03 氷海 / Small 04     Score   🪙 12   │  ← Progress + Feedback
│ Rescue 24/100                 ❤️ 10  🛡️ 3s   │
├──────────────────────────────────────────────┤
│                                              │
│                 GAME BOARD                   │
│            敵・弾・ボス・プレイヤー           │
│                                              │
│       ┌──────── BOSS INFO ────────┐          │
│       │ 氷海クラーケン  HP 62%     │          │
│       │ 低重力ホバー / クロー       │          │
│       └───────────────────────────┘          │
├──────────────────────────────────────────────┤
│ Weapon: [1 Standard] [2 3-Way] [3 Laser]     │
│ [4 Missile] [5 Beam] [6 Cannon]   [BOMB]     │  ← Combat
├──────────────────────────────────────────────┤
│ ← ↑ ↓ → 移動 / Space 発射 / B ボム            │
└──────────────────────────────────────────────┘
```

- ゲーム盤面は既存の720×820を基準にする。
- ボス情報は盤面上部の専用帯へ置き、ボス本体の上へ直接ラベルを重ねない。
- 武器パネルは盤面の外側に置き、ゲーム領域を狭めない。
- ScoreとCoinは右上にまとめ、LifeとBarrierはその下にまとめる。

## モバイル構成

```text
┌─────────────────────┐
│ S03 氷海   🪙12 ❤️10 │
│ Small 04  Rescue 24% │
├─────────────────────┤
│       GAME BOARD     │
│   ┌───────────────┐  │
│   │ BOSS HP 62%   │  │
│   └───────────────┘  │
├─────────────────────┤
│ Weapon 3-Way  [切替] │
│ [Laser][Missile][Beam]│
│ [←][↑][↓][→] [SHOT]  │
│              [BOMB]   │
└─────────────────────┘
```

- 画面幅390pxでは武器ボタンを横スクロール可能な1行にする。
- 画面幅430px以上では武器ボタンを2行にして全種類を表示する。
- ShotとBombは右下に固定し、誤タップ防止のためBombはShotより小さくしない。
- 武器切替はタップ後もゲームを一時停止しないが、選択状態を明るい枠で表示する。
- 重要な状態は絵文字だけに依存せず、`Weapon: Laser`、`Bomb 1` のようなテキストも併記する。

## 状態別UI

| 状態 | 主表示 | 操作 |
|---|---|---|
| idle | タイトル、開始、操作説明 | 開始 |
| opening | 5カット演出、スキップ | スキップ |
| playing | 通常HUD、武器パネル、ゲーム盤面 | 移動・発射・切替・ボム |
| boss | ボス帯、HP、攻撃名、危険演出 | 通常操作＋武器切替 |
| cleared | Shoot救出、スコア、10ステージ達成 | リトライ |
| gameover | スコア、到達ステージ、リトライ | リトライ |

## 武器UI仕様

- 現在武器には `aria-pressed="true"` を付ける。
- 未解放武器はロック表示と解放Stageを表示する。
- コイン消費武器は `🪙 1` のコストをボタン内に表示する。
- 現在武器名をゲーム盤面外のHUDにも表示する。
- PCは数字キー `1`〜`6` で切替する。
- PCの `Space` は発射、`B` はボムを維持する。
- スマホは武器ボタン、SHOT、BOMBを独立したタッチターゲットにする。

## ボスUI仕様

- ボス出現時、盤面上部にボス帯を表示する。
- ボス帯には名前、攻撃ラベル、武器ラベル、HPバーを表示する。
- HPバーは色だけでなく、`HP 62%` のテキストを併記する。
- Stage 10は「FINAL BOSS」バッジを追加する。
- ボスSVGは帯の下に配置し、名前・HPをSVG上に埋め込まない。
- 警告レーザーやスイープ攻撃は、HUDと混同しないよう盤面内だけで発光させる。

## レスポンシブ基準

| 幅 | 方針 |
|---:|---|
| 768px以上 | デスクトップ構成。武器パネルは横一列 |
| 573〜767px | 盤面を縮小。武器パネルは2行 |
| 430〜572px | HUDを2行化。武器パネルは2行 |
| 390〜429px | 武器パネルは横スクロール、ボス帯は2行 |
| 389px以下 | ゲーム盤面と操作パネルを縦積みし、文字を省略しない |

## アクセシビリティ

- 武器ボタン、ボム、開始、スキップ、リトライに日本語の`aria-label`を設定する。
- 色差だけで武器状態やボスHPを表現しない。
- ボスの警告フェーズは色とアニメーション速度だけに依存せず、画面上に警告ラベルを出す。
- `prefers-reduced-motion` が有効な場合、発光・揺れ・ワープ演出を短縮または静止させる。
- タッチターゲットは44px以上を目安にする。

## 実装単位

- `GameHud`: Progress、Score、Coin、Life、Barrier
- `WeaponPanel`: 解放状態、現在選択、切替操作、コスト
- `BossBanner`: ボス名、HP、攻撃ラベル、Final表示
- `TouchPanel`: 移動、SHOT、BOMB、武器切替
- `EnemyView`: SVGボス本体と表示用の装飾

## 受入条件

- Desktop 1280x720でHUD、盤面、武器パネルが重ならない
- Mobile 390x844で武器切替、SHOT、BOMBが同時に操作できる
- ボス名とHPがボスSVGに隠れない
- 武器の現在選択、未解放、コイン不足が視覚と読み上げで区別できる
- Stage 10でFinal Boss表示が出る
