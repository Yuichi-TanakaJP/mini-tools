# 株主優待期限帳 仕様

## 概要

- URL: `/tools/yutai-expiry`
- 分類: 優待・保有
- 用途: 個人の優待残高、期限、利用履歴を管理する。
- 2026-09-10時点では本番は従来保存。DB接続は工程4の隔離検証であり、切替完了ではない。

## 対象ユーザー

優待の利用・補充・残高訂正を記録する利用者。DB検証モードはSupabase Auth本人sessionが必要。

## 画面仕様

### 検証フラグ

`NEXT_PUBLIC_YUTAI_EXPIRY_DB_PREVIEW=true` の場合だけ `DatabaseRewards` を表示する。
フラグ未設定では既存ToolClientを表示し、挙動を変更しない。
DBモードは旧ToolClientをマウントせず、旧storeの読込・移行・LocalStorage書戻しを実行しない。
本番でこのフラグだけを単独有効化しない。

### 主な画面要素と入力

- カード/表の一覧、検索、期限月、期間、並べ替え、アーカイブ/使用済みの表示切替。初期値はカード・全期限・期限順・使用済みを含む・アーカイブを除く。
- 優待の追加/編集: 優待名、企業名、期限、額面、メモ、URL。追加時のみ管理単位、初期残高、銘柄/仕込み履歴の紐付け。
- 既存の紐付け、初期値、残高、単位は基本編集で変更しない。
- 消費・補充・訂正: 操作量/訂正後残高とメモ。訂正理由は必須。
- アーカイブ/解除: 残高・履歴を保持する確認付き操作。
- 利用履歴取消: 選択した1件と理由。負の残高になる取消は拒否。
- 管理単位変更: 新単位と新しい初期値/残高、必要なら額面、理由。自動換算しない。
- 優待削除: 理由と、優待/利用履歴が現在一覧から消えることの確認。

### 出力と保全

期間はすべて/今月/来月以降/期限切れ/期限未設定。端末のローカル日付を基準にし、期限当日は期限切れにしない。
基準日を表示し、1分ごとと画面復帰時に更新する。期限月の明示指定と期間ボタンは相互にリセットする。
期間ボタンの件数は全件中の未アーカイブ・残高ありを対象とし、検索や使用済み表示で変えない。表示件数とは区別する。
検索は優待名/企業/メモ/URL、前後空白と大文字小文字を無視。並べ替えは期限順（期限なしは最後）/登録日時降順/企業名順。
表は期限、単位付き残高/初期値、額面、状態を表示し、詳細を開くとカードと同じ操作/履歴を利用できる。
額面NULLは未設定、0円は0円、金額管理の額面は対象外として区別する。狭い画面では表の領域内だけ横スクロールする。
表示設定はメモリ内のみ。切替/検索/並べ替えだけではDBや旧端末ストレージを書き換えず、入力中の編集内容も保存しない。

DBの残高/初期値を単位付きで表示する。額面未設定は0にしない。補充は初期値を増やさない。
枚数は整数、金額は小数2桁まで。空欄を0へ変換せず、JSON送信で精度を失う大きな数値を拒否する。
期限/額面の空欄は未設定。新しいURLはhttp/httpsのみ。旧URLは無関係な編集で変えず、安全なものだけリンク化する。

削除/単位変更で除く優待・旧履歴は既存DB APIが監査へ保存する。他の優待/銘柄メモ/仕込み履歴は変更しない。
アーカイブ中の残高操作・履歴取消・単位変更は、解除するまで拒否する。
単位変更では旧履歴を現在の履歴一覧から除き、DB監査へ保持する。履歴全体の再計算はDBが行う。

## データ仕様

### 取得元・保存先

DB検証: 共通repository経由のworkspace RPCと9種類のreward command。
編集開始時のrevisionを保持し、成功後の再取得で表示する。LocalStorageとの二重保存や初回再importはしない。
フラグ未設定: 従来の `mini-tools:benefits:v2` と既存の移行/同期処理。本変更では切り替えない。

### fallback / 状態・エラー表示

| 状態 | 挙動 |
|---|---|
| 未ログイン | 本人データ/操作を表示せずログインを案内 |
| 初回取得中 | 取得中表示。旧保存先へfallbackしない |
| データなし | 0件表示と新規追加 |
| 取得失敗/古いcache | エラー/最終取得時刻を表示。古い状態で保存しない |
| 更新競合 | 自動上書きせず再取得後に編集をやり直す |
| 保存応答不明 | 操作を止め、同じ要求IDの再確認で二重減算を防ぐ |
| 保存済み・再取得失敗 | 書込みを重ねず再取得だけ行う |

## premium / 権限制御

DB検証はSupabaseの本人権限を使用。service roleや任意owner IDは送らない。
従来画像スキャンのpremium境界は変更しない。検証画面からスキャン/旧importを起動しない。

## 未接続・復旧

画像スキャン、旧形式の一括取り込み、累計集計等の残る従来UI互換は工程4に残る。ホームの期限通知は同じDBプレビューフラグで接続済み。実機確認・本番切替は別工程。
残高の円換算（未使用・今月期限・期限切れ）は接続済み。検索から独立して未アーカイブの正残高を集計し、枚数×現在額面／金額残高を使う。
額面NULLは換算不可件数を併記し、表示額を判明分のみと明示する。額面0円は既知額。
未使用は期限当日・期限なしを含む。今月期限は当月期限切れを含む。累計の受取・利用額は未接続。
DB全件出力/照合・確認付き復元とdashboardは接続済み。メモの一括操作、工程5の実機UAT、工程6のread/write同時切替は残件。
機能縮小を完成扱いにせず、現在の検証画面と完成条件を分ける。
コードはrevertで戻せる。旧データ/backupを削除せず、将来の復旧時は切替後のDB更新も保全してから照合する。
