# UAT: 表示テーマ（Light / Dark）

共通トークンを変更したとき、または画面の配色を触ったときに実施する。
**Light と Dark の両方**で同じ手順を通す。片方だけ見て通さない。

## 準備

- ヘッダー右上の表示テーマ切替で「ライト」「ダーク」「端末設定」を切り替えられること。
- 各画面は、切り替えたあと**リロードせずに**追従すること。

## 1. 全画面共通

| # | 確認内容 | 期待 |
|---|---|---|
| 1-1 | ヘッダーがスクロール中に半透明で背後をぼかす | 不透明な帯にならない |
| 1-2 | ページの地・カード・入力欄が別の面として見分けられる | Dark でものっぺりしない |
| 1-3 | 本文・補助文字・注記がすべて読める | Dark で薄すぎない |
| 1-4 | 入力欄の輪郭が「操作できる」ものとして見える | 装飾線と同じ濃さになっていない |
| 1-5 | 無効化されたボタン・リンクが無効に見える | 有効なものと同じ濃さではない |
| 1-6 | キーボード操作で focus 位置が見える | 色だけでなくリングで分かる |
| 1-7 | リロードしても選んだテーマが一瞬も反転しない | 白い画面がちらつかない |

## 2. 状態表示

`info` / `success` / `warning` / `error` のチップ・バナーが出る画面で確認する。

| # | 確認内容 | 期待 |
|---|---|---|
| 2-1 | 4 種類が互いに見分けられる | 同じ色に見えない |
| 2-2 | チップの文字が背景の上で読める | 前景と背景の組がずれていない |
| 2-3 | エラー表示と「下落」表示が区別できる | どちらも赤／青に潰れていない |

代表画面: 経済指標カレンダー、優待期限チェッカー、Premium ルーティン

## 3. 騰落と数値

| # | 確認内容 | 期待 |
|---|---|---|
| 3-1 | 上昇が赤、下落が青で表示される | 逆転していない |
| 3-2 | 騰落の色が success / error と混ざって見えない | 別の役割として読める |
| 3-3 | 符号（+ / −）が色と併せて出ている | 色だけに頼っていない |

代表画面: TOPIX33、日経寄与度、株価ランキング、保有銘柄

## 4. グラフ

| # | 確認内容 | 期待 |
|---|---|---|
| 4-1 | 系列が互いに見分けられる | 隣り合う系列が同色にならない |
| 4-2 | 凡例の色とグラフの色が一致する | ずれていない |
| 4-3 | 重要度など段階を示す色が、強弱の順に見える | 段階ではなく分類に見えない |
| 4-4 | 軸・目盛りの文字が読める | Dark で消えない |

代表画面: 投資部門別売買、Premium マーケット、経済指標カレンダー（重要度）

## 5. 奥行き

| # | 確認内容 | 期待 |
|---|---|---|
| 5-1 | モーダル・ポップオーバーが背後の面から浮いて見える | Dark で背景と同化しない |
| 5-2 | hover でカードが持ち上がる | 変化が分かる |
| 5-3 | 背景を抑えるスクリーンが効いている | 背後の文字が読めてしまわない |

## 6. 画面遷移とローディング

| # | 確認内容 | 期待 |
|---|---|---|
| 6-1 | ローディング表示が選択中のテーマに従う | Dark で白い面が出ない |
| 6-2 | スケルトンのアニメーションが見える | 背景と同化していない |
| 6-3 | 空状態・エラー状態も同じテーマで出る | ここだけ未対応になっていない |

## 7. 意図的な例外

次は**テーマに追従しなくて正しい**。追従していたら逆に不具合。

- ペンギン系ゲーム: ゲーム固有のパレットを維持する
- 管理画面 `/admin`: 常時 Dark。**画面幅 820px の前後で切り替わる 2 つのレイアウトが
  どちらも Dark であること**（以前はモバイル側だけライトだった）。
  スクロールバーなどネイティブ部品も Dark であること
- 企業ロゴ・証券会社ロゴなど出典側のブランド色
