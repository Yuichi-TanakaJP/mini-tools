## 国内株配当の予想（#584 Phase 1 / A3 Q2）

手順：PremiumとSupabaseへ本人ログイン後に /premium/portfolio の「保有一覧」を開き、「国内株の予想配当」を確認する。銘柄別詳細を展開したら横スクロールで右端まで読み取れるか確認する。**確認結果はPR本文に記録し、ここでチェック済みと偽らない**。

- [ ] 最新公式ready Snapshotと同じ基準日・国内株保有数量を表示する
- [ ] stock_notes_portfolio_current_dividend_projection_vの当該Snapshot行と年間予想額・銘柄数が一致する（9/21基準の場合、37銘柄 / 税引前の国内個別株分のみ）
- [ ] 年間予想額にはETF分配、MMF運用、実際の入金済み配当を含めず、対象範囲と出典日を明示
- [ ] 増配・減配・据置・比較不能を区別し、比較不能のDPSを0円と扱わない
- [ ] 配当単価変化の寄与は比較可能な銘柄のみを対象とし、投資による株数増分を混同しない
- [ ] 取得失敗/権限なし/Source欠損/別Snapshot/後日公表DPSを検出した場合、予想全体額を出さず0円にもならない（合成fixture、本番データは変更しない）
- [ ] 0円の無配銘柄と、未取得・比較不能の「—」を区別
- [ ] 画面幅390pxのスマホで、既存の「保有一覧」・分析カード・商品一覧が壊れず、追加表は詳細から横スクロールできる
- [ ] 本人の年内実受取額・税引後金額は「未確認」であり、予想ランレートを実入金と呼ばない
- [ ] GitHub PRの静的/単体テスト・プレビュー・認証後の本番UATを独立して記録。CIが開始前に失敗したらPASS扱いにしない

### 構成ドーナツ切替の回帰

- Premiumログイン後、保有一覧を開く。業種→景気感応度→資産クラス→業種を連続選択し、ラベル・金額・割合が選択に一致する。通信・待機スピナーを追加しないローカル操作である。
- キーボードで分析軸selectと対象ボタンを操作でき、選択中の対象はaria-pressedに反映される。狭い画面でも横にはみ出さず、多い凡例はスクロールできる。
- 外部参照資産は分析対象外の説明があり、総資産評価額とは区別できる。既存の配当パネルが残る。
- 合成fixtureで、未分類あり／評価額未取得／0円のみ／分類取得失敗を確認する。失敗→資産クラスへ切替→分類軸へ復帰しても、失敗を未分類100%で描画しない。

## 分析軸・分類と下部の連動

確認環境: 認証済みPreview/本番の保有一覧。異常系は合成fixtureで再現し、本番データを変更しない。実施結果はPR本文へ記録する。

- 7分析軸が常にbuttonで見える。Tab/Enter/Spaceで操作でき、選択状態がaria-pressedで分かる。
- 業種→景気感応度→資産クラス→口座種別→銘柄別を順に押し、下の分類別配当と商品見出しも一致する。通常の閉じた状態でグラフcardの高さが変わらない。
- シクリカル等の分類を選ぶとpieが該当部分を強調し、配当と商品がその範囲だけになる。グラフ分母はscope全体を維持する。再押下/すべて表示で戻る。
- 全明細から上位以外の分類を選べる。その分類だけの商品・配当が表示され、図はその分類と残余を正確に示す。未分類も独立して残る。
- 分類を選んでから別軸・別scopeへ変えると選択が解除される。同じ軸/scopeの再押下では保持する。元の軸へ戻っても前のfilterが意図せず残らない。
- 口座別で同じ銘柄を複数口座に保有する合成ケースを確認する。100/300株・評価額比9:1の場合、配当は1:3へ分かれる。商品数量と口座名も同じ範囲になる。
- 選択外の未確認を、選択内や全体の確定額へ足さない。選択内が未確認ならNULL、国内株がなければ対象なしを表示する。
- totals金額不整合、別snapshot、重複source、数量不一致、空白/非有限数値、未来公表日ではsubsetも確定しない。正しい0円は維持する。
- 評価額未取得も商品一覧に残る。分類取得失敗→資産クラスへ切替→元軸へ復帰で、誤った未分類100%や古い選択ラベルを表示しない。
- 375px幅でも全ボタンと商品明細を読め、横はみ出しがない。配当の詳細表だけ既存の横スクロールを許容する。

検証: `npx vitest run app/premium/portfolio`、変更TSX/TSのESLint、`npm run build`、`npm run check:navigation -- --base <base>`。操作確認は合成実コンポーネントと認証画面で別に記録する。

- 分類別配当のbuttonをEnterで選択・解除しても、対象外メッセージへの切替でfocusがbodyへ落ちない。「ほかの分類（全体に戻る）」から戻った際は「すべて表示」へfocusが戻る。

## 企業グループ集中を詳細画面へ分離

確認環境: ローカル合成データの実Workspace、および認証済みPreview/本番。結果はPRへ記録する。

1. 「保有一覧」の先頭が資産/配当サマリーになり、「企業グループ集中の詳細」や企業グループのcardが表示されないこと。
2. 「詳細メニュー → 企業グループ」で既存内容が表示され、メニューに選択中画面名とaria-pressedが反映されること。
3. 「保有一覧」へ戻ると企業グループが消え、資産/配当/7軸が表示されること。繰返し切替で追加取得せず、古いerrorを他画面へ表示しないこと。

5. キーボードで詳細メニューを開いて選択/戻る操作ができ、375px幅でメニューが横にはみ出さないこと。

今回の局所state切替はNodeのSSR単体テストだけでは操作経路を検証できないため、実コンポーネントのブラウザー回帰で確認する。新規DOM依存やsource文字列一致のテストは追加しない。関連Portfolio既存テストとbuildも実施する。
