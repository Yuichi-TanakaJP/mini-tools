# 業界マップ UAT

## 前提

- Premium仮ログインで `/premium` に入れる
- Supabaseにログインでき、`stock_notes_taxonomy_*` に業界マップが保存されている
- Supabase未設定・未ログインの状態も再現できる
- 企業紐付けのあるdomain（企業経済圏）と、無いdomain（半導体等）の両方を確認できる
- 上場企業（銘柄コードあり）と非上場・海外企業（銘柄コードなし）の両方を確認できる

## 正常系

- [ ] Premiumホームに「業界マップ」カードが表示される
- [ ] `/premium/industry-map` がPremiumログイン後に表示される
- [ ] domainチップに表示名・領域数・関係数が出て、切り替えるとマップ全体が変わる
- [ ] 集計に領域数・横断する関係数・紐づく企業数・紐づくテーマ数が出る
- [ ] 5つの表現を切り替えられ、選択中のインジケータが移動する
- [ ] 表現ごとに、そのビューが答える問いの説明が出る

### 階層ツリー

- [ ] 初期表示で深さ1まで展開されている
- [ ] 行をクリックすると展開・折りたたみが切り替わり、詳細パネルに反映される
- [ ] `layer`（root / origin / service 等）を持つ領域にバッジが出る
- [ ] 企業が紐づく領域に「企業 n」バッジが出る
- [ ] 横断する関係を持つ領域に「関係 n」バッジが出る
- [ ] 階層に接続していない単独領域に「階層未接続」バッジが出る

### 放射マップ

- [ ] 中心に主たる木、外側に葉と未接続領域が配置される
- [ ] ラベルが読める大きさで、domainを変えても文字の大きさが変わらない
- [ ] 領域をクリックすると選択され、祖先への経路が強調される
- [ ] 横断関係を持つ領域に印が出る

### 図の拡大縮小・移動（放射マップ / 関係ネットワーク）

- [ ] ＋ / − で拡大縮小でき、倍率の%表示が変わる
- [ ] 上限・下限に達すると該当ボタンが押せなくなる
- [ ] ⟲ で等倍・移動なしに戻り、等倍のときは押せない状態になる
- [ ] ドラッグで図を移動でき、カーソルが grab / grabbing に変わる
- [ ] ドラッグしたあとに領域が選択されない（クリックと区別される）
- [ ] Ctrl / ⌘ + ホイールで、ポインタ位置を固定したまま拡大縮小できる
- [ ] ホイール単体では拡大縮小せず、ページが縦スクロールする
- [ ] ダブルクリックでその位置を中心に拡大する
- [ ] domainを切り替えると等倍に戻る
- [ ] ドラッグ後にフォーカス枠（黒い四角）が残らない
- [ ] キーボードのTabで領域に移動したときはフォーカス枠が出る
- [ ] スマホで、等倍のときは1本指で画面を縦スクロールできる
- [ ] スマホで、2本指のピンチで拡大縮小できる
- [ ] スマホで、拡大後は1本指で図を移動できる

### 関係ネットワーク

- [ ] 6種の関係が色分けされ、凡例と一致する
- [ ] 関係種別のON/OFFで線が増減する
- [ ] 件数0の関係種別は押せない状態になる
- [ ] 「再配置」で配置がやり直される
- [ ] 領域を選ぶと、その隣接だけが強調され、他が薄くなる
- [ ] 同じdomainを開き直すと同じ配置になる（乱数を使っていない）

### マトリクス

- [ ] 企業 × 領域で、色が戦略上の位置づけ、ツールチップが関与の仕方と確度を示す
- [ ] 上場企業の列に銘柄コードと国コードが出る
- [ ] 非上場・海外企業の列に、銘柄コードの代わりに上場区分が出る
- [ ] `draft` の企業に「下書き」が出る
- [ ] 非上場企業を含むとき「銘柄コードのない企業は売買対象として扱えません」と表示される
- [ ] テーマ × 領域で、関係（対象範囲・注目点・監視軸等）が表示される
- [ ] 空セルが「紐付けなし」であり、優劣や売買判断を意味しないと説明されている
- [ ] 行見出しをクリックすると詳細パネルに反映される
- [ ] 紐付けが0件のdomainでは「まだありません」と表示される
- [ ] 企業ビューだけが取得できないとき、赤系で「取得失敗」と表示され、0件表示と区別できる（他のビューは通常どおり動く）
- [ ] そのとき集計の企業数が `—` になる

### テーブル

- [ ] 全領域が一覧され、件数（表示件数 / 全件）が出る
- [ ] 領域・種別・階層・企業・横断関係で並べ替えられ、方向が切り替わる
- [ ] 行をクリックすると詳細パネルに反映される

### 詳細パネル

- [ ] 種別・layer・status・表示名・slug・階層パスが出る
- [ ] 下位領域、横断する関係、紐づく企業、紐づくテーマが出る
- [ ] 企業に役割・関与の仕方・確度・基準日が出る
- [ ] 上場企業に銘柄コードのバッジが出る
- [ ] 基準日がタイムスタンプでも `YYYY-MM-DD` で表示される
- [ ] 企業名と銘柄名が同じとき、名前が二重に出ない
- [ ] 下位領域と横断関係の項目をクリックすると、その領域へ移動する
- [ ] 横断関係に向き（→ / ←）と関係の説明が出る
- [ ] 企業欄に「紐付けは事実の整理であり、売買の推奨ではありません」と表示される

### 検索・フィルタ

- [ ] 検索でヒットした領域が強調され、畳まれていても祖先が展開される
- [ ] 検索を消すと元の畳み方へ戻る
- [ ] 種別フィルタで対象外の領域が薄くなる（表では除外される）
- [ ] 種別フィルタは最後の1つを外せない

## 異常系・境界

- [ ] Premium未ログインで `/premium/industry-map` を開くとログインへリダイレクトされ、ログイン後に戻る
- [ ] Supabase未設定のとき「未設定」と表示され、空データとして表示されない
- [ ] Supabase未ログインのとき「ログインしてください」と表示される
- [ ] 取得失敗のとき「取得できませんでした」と表示され、0件と区別できる
- [ ] 業界マップが0件のとき「まだありません」と表示される
- [ ] 検索・フィルタで0件のとき、その旨が表示される

## 表示上の禁止事項

- [ ] 画面に保存・編集・更新・削除の操作がない
- [ ] 買う／売る／保有するの判断が表示されない
- [ ] `strategic_role` / `control_type` / `confidence` が数値スコアやレーダーに変換されていない
- [ ] サンプルデータや推測値が表示されていない

## 表示・レスポンシブ

- [ ] スマホ幅で表現切り替えがアイコン表示になり、5つとも押せる
- [ ] スマホ幅で集計が2列、domainチップが横スクロールになる
- [ ] 図が画面の高さを占有しすぎず、横スクロールが発生しない
- [ ] OSの「視差効果を減らす」設定でアニメーションが止まる
