# 分析軸と配当・商品構成を連動させる

対象はV2 Phase 6 / UI-3の既存保有表示。ユーザーが分析軸を常に選択でき、選択内容でグラフだけでなく下の配当・商品構成も変わる形を要望したため、axis/scope/categoryを画面内の共通stateへまとめる。

7軸は常時button表示。分類buttonで絞り込み、軸/scope変更で解除する。多分類は上位6＋その他、未分類は別。全明細から小さい分類も選択できる。PC320px/モバイル300pxのSVGと予約領域で、通常の軸切替による高さの変動を抑える。

責務は表示内の分類・数量による配分のみ。株数分割の再補正、配当Fact保存、外部資産の分類統合を追加しない。部分範囲の配当表示は、DB sourceのcoverage/snapshot/件数/金額整合と数量一致を証明できた場合に限る。未確認を0円へ変換せず、選択範囲と全体額を混同させない。元のDB完全合計が行金額と不一致なら、新たに保留する。

DB/API/Producer/R2/Scheduler、他タブの履歴・方針は変更しない。V2全体の完成宣言は行わない。sourceと合成データのテストに加え、実画面で押して切替・解除・高さ・狭幅を確認する。
