# 企業グループ集中を詳細メニューへ移す

ユーザーから、保有一覧の上部にある「企業グループ集中の詳細」が邪魔なので別の場所へ移してほしいという指摘を受けた。

V2 Phase 6 / MiniTools UI-3の局所表示変更として、既存の詳細メニューに「企業グループ」を追加する。専用ローカル画面で既存の集計・エラーを表示し、保有一覧の先頭は資産・配当サマリーにする。別URLや新APIを作らず、取得済みpropsと既存タブ状態を再利用する。主ナビの項目数は増やさない。

受入: 保有一覧から企業グループの開閉行がなくなり、詳細メニューから既存内容を開いて保有一覧へ戻れる。未認証/公式保有なし/取得失敗の契約を維持する。DB・認証・集計・保存・Schedulerは変更しない。プラットフォーム全体の完成条件を変更しない。
