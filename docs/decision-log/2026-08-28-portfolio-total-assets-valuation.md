# 2026-08-28 公式保有と外部参照資産を総資産評価額へ合算する

## 結論

`/premium/portfolio` の保有一覧では、最新の `official` ready snapshotと、最後に読み取り可能な
`external_reference` ready snapshotの円評価額を「総資産評価額」として合算する。同時に、公式保有と
外部参照資産の評価額・position件数・基準日・取得状態を内訳として表示する。

`official` と `external_reference` は、データの正しさや証券会社の格付けを表す名称ではない。
SBI証券等の特定機関を自動的にofficialと判定するものでも、口座名・口座タイプが分かる資産を
external扱いにするものでもない。現在はsnapshotへ保存された `portfolio_scope` による取得・更新経路の
区分である。

## 背景

分離導入時は、基準日、通貨換算、重複保有、原価、分析対象の扱いが未確定だったため、
外部資産を公式保有の評価額へ合算しなかった。しかし、ポートフォリオ画面で最初に必要なのは、
管理対象として登録済みの資産全体がいくらかを把握できることである。

2026-08-28の実データ確認では、公式ready snapshotと外部参照ready snapshotの双方に
評価額があり、両scopeの合算結果が個別集計の和と一致することを確認した。確認時点では、
両scope間にinstrumentの重複はなかった。

## 決めたこと

- 総資産評価額は、公式保有評価額と外部参照資産評価額の合計とする
- 内訳として両scopeの評価額、position件数、基準日、外部資産の取得状態を表示する
- 保有一覧では、両scopeの評価額比率をドーナツ図と数値凡例で表示し、金額カードだけを読み比べなくても構成を把握できるようにする
- 評価額未取得positionがある場合は、確認できた金額の合計であることと未取得件数を明示する
- 取得額と含み損益は、外部資産に原価がない場合があるため、現段階では公式保有だけを表示する
- 公式保有の商品別構成比は、今回のPRでは公式保有内の比率のまま維持する
- 意思決定context、役割別配分、重複排除、scope名称の見直しは別工程とする

## 理由

総額を隠したままscope別表示だけを行うと、全資産を把握するためにユーザーが手計算しなければならない。
一方でscopeを直ちに廃止すると、評価基準日や原価の違いを追跡できなくなる。総額と内訳を同時に出すことで、
全体把握とデータ監査の両方を成立させる。

## 影響範囲

- 保有一覧の先頭に総資産評価額を表示する
- 従来の公式評価額は「公式保有」として残す
- 外部参照資産の評価額を同じ画面に内訳表示する
- 外部資産の口座別明細と状態表示は「口座・取込」に残す
- `portfolio_scope` の保存契約や既存データは変更しない

## 残課題

- `official` / `external_reference` という名称を、主データ・補助データ等の実態に合う名称へ変更するか
- 複数scopeに同じinstrumentが入った場合の重複排除
- 外貨建て資産のFX基準日と換算品質
- 外部資産を商品別構成・意思決定contextへ含めるルール
