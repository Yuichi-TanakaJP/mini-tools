# Portfolio表示状態と推薦ラベルの修正

対象はMiniTools UI-4 / V2 Phase 6の読み取り画面の品質改善。V2全体の完成条件は変更しない。

- 外部参照snapshotのsupersededは取得失敗ではなく、履歴上の置換済み状態として表示する。置換先が公式snapshotとは限らないため、公式への統合完了とは推測しない。
- readyがなければ旧明細は再集計しない。readyが残る場合は既存の最後の成功データと置換済み警告を保持する。
- 推薦がinstrument_idではなくstock_idを参照するとき、取得済みの本人のinstrumentからコード・名称を解決する。DBの参照を書き換えず、取得範囲・認証・RLSを変更しない。
- 表示密度の整理は後続の別PR。今回の不具合修正にタブ構成変更を混ぜない。

受入条件: 置換済みが取得失敗/未登録と区別されること、旧明細が重複加算されないこと、解決可能な推薦候補がコード・銘柄名で表示されること。
