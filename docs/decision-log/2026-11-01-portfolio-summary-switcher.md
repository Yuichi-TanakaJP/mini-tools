# 保有サマリーを分析の入口にする

## 背景と判断

ユーザーから、上部カードをボタンにしてグラフ／一覧を切り替え、公式保有の取得額・損益を別の指標へ置き換える要望があった。総資産・年間予想配当・個別株評価額・投信評価額を入口にする。対象選択と表示形式を分け、一覧へ切り替えても見ていた範囲を維持する。

## 理由と影響範囲

資産種類をすぐ選び、構成と明細を往復できるようにする。上部の保有全体額と選択範囲を区別し、外部参照を含む総資産と登録保有だけの分析の差を明記する。投信・個別株は既存assetTypeを使い、新しい分類や通信を作らない。配当の数量検証・保留・部分和契約、取得原価の明細は変更しない。

対象はV2 Phase 6 / MiniTools UI-3。DB・認証・API・保存は変更せず、プラットフォーム全体の完成条件は維持する。

現在仕様は[Portfolio](../specs/tools/portfolio.md)、確認条件は[UAT](../uat/portfolio.md)に記載する。
