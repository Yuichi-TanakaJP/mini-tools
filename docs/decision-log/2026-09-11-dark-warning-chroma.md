# 2026-09-11 ダークの警告色の彩度を下げる

## 背景

ダークテーマの警告バナー（優待の「あと 3 営業日」など）について、
オレンジが強すぎるという指摘を受けた。

当時の値は `--color-warning-text: #fbae67`（L81 / C0.126 / hue 62）で、
明度も彩度も高く、暗い地の上でかなり目立つ状態だった。

## 今回決めたこと

**Dark の warning ファミリーだけ彩度倍率を ×0.65 にする。色相（琥珀 hue 62）と明度は動かさない。**

| トークン | 変更前 | 変更後 |
|---|---|---|
| `--color-warning` | `#d17f26` | `#be8859` |
| `--color-warning-text` | `#fbae67` | `#e8b68a` |
| `--color-warning-bg` | `#3d2309` | `#372617` |
| `--color-warning-border` | `#6d4113` | `#63462d` |

Light 側は据え置く。

## 判断理由

- **暗い地の上では暖色の彩度が強く感じられる。** 同じ値でもライトより刺さって見えるので、
  Dark 側だけ落とすのは配色として根拠のある扱い。
- **警告は「注意して」であって「エラー」ではない。** 状態色の中では本来いちばん落ち着いていてよく、
  彩度倍率 ×1.00 は役割に対して高すぎた。
- **色相は動かさない。** 琥珀のままなら「警告」という意味は保たれる。
  金・マスタード寄りへずらす案も比較したが、静かになる代わりに
  「警告」ではなく「補足」に見える方向へ寄るため採らなかった。
- **明度は下げない。** 明度も下げる案（文字通りの調光）はいちばん沈むが、
  本文のコントラストが 7.9 → 6.2 まで落ちる。明るい部屋で読みにくくなる方を避けた。

## 確認したこと

彩度を下げると、近い暖色と区別がつかなくなる可能性がある。距離を測って確認した。

| 相手 | dE | 判定 |
|---|---|---|
| `rise`（上昇の赤） | 0.117 | OK |
| `error` | 0.097 | OK |
| `severity-4` | 0.098 | OK |
| `chart-4` | 0.093 | OK |
| `severity-3` | 0.070 | OK |
| `chart-10` | 0.067 | OK |

いちばん近いのは `severity-3` と `chart-10`（どちらも琥珀系）。

当初この 2 組を距離チェックへ追加したが、**Light 側で落ちた**。
調べると Light では `warning` `#a55d00` / `severity-3` `#9c6900` / `chart-10` `#a26000` が
ほぼ同色（dE 0.009〜0.033）で、これは今回の変更ではなく元からの状態だった。

これは不具合ではないと判断して、追加したチェックを外した。
3 つとも「注意・中間」を意味しており、**意味が食い違わない**。
距離チェックの対象は「青いのに下落ではない」「赤いのにエラーではない」のような、
取り違えると利用者が損をする組に限る、という方針を仕様へ書き足した。

なお変更前後の距離は dE 0.049 で、「色が変わった」と分かる程度には動いている。

## 影響範囲

- `app/globals.css` の `html[data-theme="dark"]` の warning 4 トークン。
- 参照しているすべての画面（優待期限、経済指標、ルーティン、stock-notes ほか）。
- Light テーマは変更なし。
