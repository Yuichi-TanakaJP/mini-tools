# 2026-08-30 共通ヘッダーに表示テーマ切替を置く

## 背景

- 明るいホーム画面は暗所で光刺激が強く、利用者がつらさを感じることがある。
- 共通カラーパレットには Dark 候補があったが、ユーザーが画面から選ぶ機能はなかった。
- テーマ適用をクライアントのマウント後だけに行うと、保存済みテーマが Dark でも最初に Light が表示される。

## 今回決めたこと

- 全ページ共通の上部ヘッダーに「端末設定」「ライト」「ダーク」の選択 UI を置く。
- 初期値は「端末設定」とし、明示選択は LocalStorage に保存する。
- 保存値または端末設定から解決した Light / Dark を、React のハイドレーションより前に `<html data-theme>` へ適用する。
- 色は共通 CSS トークンで切り替え、まずホーム画面と共通 UI を Dark 対応範囲とする。

## 判断理由

- 「端末設定」を初期値にすると、すでに OS 側で設定した利用者の意図を追加操作なしで反映できる。
- Light / Dark の明示選択も残すことで、利用場所や時間帯に応じて端末設定と異なる配色を固定できる。
- 切替を共通ヘッダーへ置くと、ホームから見つけやすく、別ページでもすぐ戻せる。
- LocalStorage はログイン不要という既存方針に合い、配色情報をサーバーへ送らずに保持できる。

## 影響範囲

- 共通ヘッダー、ページ背景、共通 CSS トークンを参照するカード・入力・文字・境界線、モバイル下部ナビ。
- 色を直接指定している個別ツール固有 UI は、自動的に完全な Dark 配色へ変わるとは限らない。
- `app/layout.tsx` で初回適用スクリプトを実行する。`suppressHydrationWarning` は、このスクリプトが `<html>` 属性を先に変えることだけを対象とする。

## 残課題

- 個別ツールの直書き色は、各ツールを Dark 対応するときにコントラストを確認してトークン化する。
- Midnight Navy は選択肢に追加せず、将来候補のままとする。
