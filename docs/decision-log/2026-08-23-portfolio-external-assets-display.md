# 外部資産の表示と公式集計を分離する

## 結論

MiniToolsでは、iDeCo・企業型DC・海外口座・暗号資産・現金等をポートフォリオの正式な管理対象として表示する。ただし、今回の表示実装では公式保有の評価額・構成比・意思決定集計へ自動合算しない。

保存経路は従来どおり、次の流れとする。

> ChatGPTで相談・確認 → stock-notes API → Supabase → MiniToolsで表示

## 背景

外部口座等は「おまけ」ではなく、ポートフォリオ全体を把握するために必要なデータである。一方、証券会社CSVによる公式保有と、参考残高として登録した外部資産を直ちに一つの総額へ合算すると、通貨・基準日・重複保有・分析対象外の扱いが不明なまま二重計上する危険がある。

## 決めたこと

- snapshotの `portfolio_scope=official` と `external_reference` を読み分ける
- 公式の `currentSnapshot` と `dbPositionSnapshot` は `official` のready行だけから選ぶ
- 外部資産は「口座・取込」内の独立セクションで、基準日・取得元・評価額・明細を表示する
- 外部資産の状態は、未登録・登録済み・取得失敗を区別する
- 評価額未取得は `—` と表示し、0円とは扱わない
- MiniToolsには外部資産の登録・更新・削除入力を追加しない
- 外部資産取得に失敗しても、公式保有・review・policyの表示は壊さない

## 今回の範囲外

次の項目は、外部資産を意思決定contextや総合配分へ統合する別工程で定義する。

- 公式資産との合算対象
- 通貨換算と評価日
- 重複保有の判定
- 配分分析から除外する資産
- 外部資産の鮮度・更新期限

## 影響

MiniToolsを開けば、保存済みの外部資産を公式保有と混同せず確認できる。現段階では「表示できること」と「意思決定集計に含めること」を分けるため、公式保有の既存評価額や構成比は変わらない。
