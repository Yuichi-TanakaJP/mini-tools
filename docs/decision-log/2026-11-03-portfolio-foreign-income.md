# 外国株・ETFの参考年間インカムを既存為替で表示する

対象はPortfolio V2 Phase 6 / MiniTools UI-3の配当読取拡張。外国株・ETFのインカムを、保有基準日と換算根拠付きで確認できることを受入条件とする。

登録済みpositionの為替を再利用し、専用為替取得サービス・定期実行・Market InfoのProducer/R2/Scheduler変更は加えない。恒久的な為替更新経路は別途検討する。

円換算と公開資料の意味判定はStock Notes viewが所有し、MiniToolsは本人の現在snapshotのposition別結果を読むだけとする。上部の国内株予想は維持し、無配方針による見込み0とETFの過去12か月分配参考額を併記する。確認できない値を0として補完せず、参考小計は全体確定額と区別する。

外部参照の資産分類を新たに推測しない。既存7軸の条件で絞り、未知の業種等は未分類として扱う。資産ドーナツの対象・分母は維持する。MMFの利回り、税引後額、実際の受取配当、全資産インカム完成はこの変更の範囲外。

仕様: [portfolio](../specs/tools/portfolio.md)。確認手順: [portfolio UAT](../uat/portfolio.md)。


本番確認で、既に置換された外部snapshotを現行の通信失敗と同じ扱いにすると、公式保有から計算済みの外国参考額まで隠れることを確認した。supersededの外部snapshotと旧positionは現在の読取対象から外し、公式保有を通常どおり読む。現行外部snapshotのerror/loadingはこの修正で成功扱いへ変えない。金融元データやDB状態を変更して回避しない。


ユーザー指摘により、配当カードの主表示を国内額から国内＋海外の年間配当見込み総計へ変更する。カード内の複数金額と長い説明は取り除き、内訳・計算条件はカード行の直下へ移す。元の国内予想・海外参考額・対象外の計算は変えず、誤った完全合計や不明な0は作らない。
