# 配当を保有一覧の上部と構成グラフで確認する

対象: V2 Phase 6 / MiniTools UI-3。上部が資産・原価・損益・件数に偏り、年間の配当見通しが下へ隠れていた。配当も上部へ出し、内訳をグラフで理解したいというフィードバックに対応する。

4指標のうち件数を補足へ移し、年間予想配当（国内株・税引前）を上部へ置く。保有全体の年間額と選択分類の額を区別する。部分和を全体額にしない既存契約を保持し、未確定主値「—」と確認済み分を併記する。

配当構成は小さなsliceが増える別ドーナツでなく、分類ごとの金額と大小を比較できる横棒とする。既存7軸・scope・分類の共通状態を再利用し、詳細比較と銘柄表をその下へ配置する。分母を確認済み額と明示し、未確認を0円にしない。入金額・税引後・配当時系列は追加しない。DB/API/認証/Producer/R2/Schedulerは変更しない。

受入: 上部で予想年額/未確定を判別でき、横棒で同分類の配当額を比較し、選択が配当・商品へ連動する。数量按分・保留・分類errorの既存安全契約を維持する。プラットフォーム全体の完成条件は変更しない。

画面配置: 上部サマリー → 共通7軸/scope選択 → 資産ドーナツと配当横棒の2列比較 → 配当の比較指標・明細 → 商品構成。900px以下は1列にし、両グラフは同じ共通選択を使う。
