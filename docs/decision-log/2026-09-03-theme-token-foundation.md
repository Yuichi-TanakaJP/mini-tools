# 2026-09-03 全画面テーマ統一のトークン基盤

## 背景

- PR #545 で Light / Dark の切替基盤を追加したが、画面固有の直書き色には適用されなかった。
- 棚卸しでは TSX / CSS 153ファイル中68ファイルに色リテラルがあり、同じ白いカードや補助文字にも複数の近似色が使われていた。
- 基本13トークンだけでは、状態色、騰落、グラフ、モーダル、影を各画面が独自実装せざるを得なかった。

## 今回決めたこと

- UI の共通コンセプトを「Quiet Financial Workspace」とする。
- トークンを Surface / Text / Border / Action / Semantic / Financial direction / Data visualization / Elevation / Global header に分類する。
- 状態色は foreground / background / border の組として Light / Dark 両方に定義する。
- 共通ヘッダーは安定したナビゲーション帯として両テーマで深いチャコールを維持する。
- ゲーム固有色と出典側のブランド色は移行対象から除外できるが、例外理由を記録する。

## 判断理由

- 色名ではなく役割で参照すると、画面をまたいで意味を統一しながらテーマごとの明度を調整できる。
- Dark を後付けの反転として扱わないことで、白い面の残存、低コントラスト、反対テーマのローディング表示を防ぎやすい。
- グラフ色とUI色を分離すると、可視化の識別性を保ちながらカード・本文の統一を進められる。

## 影響範囲

- `app/globals.css` の共通テーマトークン。
- 共通ヘッダー、テーマ選択、共有モーダル、ナビドロワー、ホーム画面。
- 後続の #573 / #572 で各画面を同じトークン契約へ移行する。

## 残課題

- 優待・市場・Premium画面のローカルパレット移行。
- 管理画面を常時Darkの例外にするか、選択テーマ対応にするかの確定。
- 直書き色の自動監査と全画面 Light / Dark UAT。
