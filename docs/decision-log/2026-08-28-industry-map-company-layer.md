# 業界マップの軸を「銘柄」から「企業」へ変える

## 結論

業界マップの紐付けは、`stock_notes_stock_taxonomy_links`（銘柄 × 領域）ではなく、Supabase 側で業界マップ向けに用意されたビュー `stock_notes_industry_map_company_links_v1`（企業 × 領域）から読む。上場企業は銘柄コードを添えて表示し、非上場・海外企業もそのまま扱う。

このビューはリポジトリ外で管理されるため、**取得に失敗しても画面全体を失敗にしない**。企業レイヤーだけを空にし、「0件」ではなく「取得失敗」と明示する。

## 背景

Supabase に企業レイヤーが追加された（2026-08-28 時点で確認）。

| 追加 | 件数 | 中身 |
|---|---|---|
| `stock_notes_company_entities` | 31 | 企業。NVIDIA / Waymo / Tesla / Pony.ai / HIF Global / Synhelion 等の非上場・海外を含む |
| `stock_notes_company_taxonomy_links` | 44 | 企業 → 領域 |
| `stock_notes_company_stock_links` | 4 | 企業 → 銘柄（国内上場のみ） |
| `stock_notes_theme_company_links` | 27 | テーマ → 企業 |
| `stock_notes_industry_map_company_links_v1` | 44 | 上記を非正規化した業界マップ向けビュー |

これまで半導体・自動運転マップで「紐づく銘柄 0」だったのは、主要プレイヤーが国内上場銘柄ではないためだった。企業レイヤーはその欠落を埋めるもの。

## 決めたこと

- マトリクス、詳細パネル、テーブル、バッジ、集計の軸を「銘柄」から「企業」へ変える
- 上場企業は銘柄コードと国コードを添える。非上場・海外は上場区分を出す
- `company_status` が `draft` の企業に「下書き」を出す
- MiniTools はビューだけを読み、基底3テーブルを直接読まない
- 企業レイヤーの取得失敗は画面全体の失敗にせず、マトリクスで赤系に明示し、集計の企業数を `—` にする
- `company_status` / `listing_status` / `country_code` は検証せず、既知の値だけラベル化して残りは元の値を出す
- `strategic_role` / `control_type` / `confidence` は配色に使うので検証し、未知の値の行は落とす

## 理由

### なぜ銘柄軸をやめるか

業界マップの目的は産業構造の俯瞰であり、「自分が買える銘柄かどうか」とは別の軸である。半導体マップに NVIDIA や TSMC が出ないのでは俯瞰にならない。企業を軸にすれば、上場・非上場を問わず構造を描け、上場企業には銘柄コードを添えるだけで済む。

### なぜ移行しても表示が壊れないと言えるか

切り替え前に実データで検証した。既存の `stock_taxonomy_links` の現行44行と、ビューの現行44行は **(銘柄, 領域) の組・`strategic_role` / `control_type` / `confidence` の値ともに完全一致**（差分0件）。企業側のメタにも `migration_source` が入っており、既存データの移行であることが確認できた。したがって今日時点の表示は変わらず、今後の企業追加ぶんだけが増える。

### なぜビューだけを読むか

基底3テーブルを結合し直すと、Supabase 側のスキーマ変更に MiniTools が追随し続けることになる。ビューは業界マップ向けに用意されたものなので、これを境界にする。

### なぜ企業レイヤーだけ失敗許容にするか

このビューはリポジトリの migration に含まれず、Supabase 側で直接管理されている。定義や権限が変わったときに、業界マップ全体が真っ白になるのは影響が大きすぎる。構造（領域・関係）は必須テーブルから読めるので、企業レイヤーだけを落として続行し、失敗を隠さず表示する。

## 影響と残課題

- 企業レイヤーのリンクは現在 `business-ecosystems` のみ。半導体・自動運転・合成燃料は「紐づいた企業はまだありません」と表示される。企業31社のうち27社はまだ領域リンクがない
- 企業関連テーブルは stock-notes リポジトリの migration に含まれていない。schema の正本化は stock-notes 側の課題として残る
- `authenticated` ロールでのビュー読み取り権限は未検証。匿名キーでは0行で漏洩がないことだけ確認済み。実ログインでの確認が UAT に必要
- `stock_notes_theme_company_links`（テーマ → 企業、27件）は今回は使っていない。テーマ軸は従来どおりテーマ → 領域で表示する
