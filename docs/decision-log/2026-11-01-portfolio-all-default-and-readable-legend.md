# 保有分析をAllで開始し、分類名の見切れを解消する

ユーザーから「株か投資信託か見えない」「初期画面はAllで全部載せがいい」と指摘があった。PCの左右比較用CSSで凡例を168pxに縮めた一方、gridのalign-content:centerを維持したため、多数行の先頭が上側へ隠れていた。

初期選択を資産クラス/登録保有全体/分類未選択へ変更する。凡例は上揃え・自然高にして、分類名を省略せず折り返す。一定の最小領域で通常の軸切替時の高さを確保し、内容超過時は文字と金額が見えることを優先する。上位6＋その他と全分類への到達は維持する。

対象はV2 Phase 6 / MiniTools UI-3の保有表示。配当/source/quantity検証・DB・認証・保存・外部資産境界は変更しない。受入は全保有を対象とする初期選択、凡例の先頭/末尾/長い名前の可読性、既存の選択連動維持。プラットフォーム全体の完成条件は変更しない。
