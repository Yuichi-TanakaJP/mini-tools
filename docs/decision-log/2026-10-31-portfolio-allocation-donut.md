# 保有構成のドーナツを分析軸で切り替える

対象: V2 Phase 6の現在地表示、MiniTools UI-3の既存構成分析改善。受入条件は業種・景気感応度等7軸の切替、対象範囲と未分類の明示、既存集計・配当の維持。V2全体の完成判定は変更しない。

ユーザーの要望により、公式保有／外部参照という取得区分のドーナツを、既存の分類集計を使う保有構成へ置換する。初期表示は東証33業種／個別株のみ。全軸でドーナツを維持し、全分類を凡例に残す。重複する下部分析は統合する。

外部資産の商品別分析は既存計画で未定義のため、勝手に混ぜず対象外を明記する。出所・基準日の確認は口座・取込に保持する。DB/API、Market Info、配当計算は変更しない。
