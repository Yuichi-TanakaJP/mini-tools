# アロケーション・タイルをfaviconに採用

ブラウザーのタブにアイコンを付けたいという依頼を受け、既存PNGの参照追加を用意した後、ユーザーからClaudeと独自デザインを作りたいという指示を受けた。

個人データ・コードを含まないデザインbriefをClaude Opus 5.5（medium）へ送り、M・資産配分タイル・軌道の3案を作成。CodexがSVGの安全性を検証し、16/24/32/48pxと明暗タブの比較画面を作成した。ユーザーは「アロケーションタイルがいい」と選択した。

採用案は青い主区画と青/シアンの小区画で資産配分を表す。小サイズで区画間がつぶれない専用SVGをfaviconへ使用し、16/32pxのICOを互換用に用意する。SVGは静的図形のみ。PNGはSVGを既存sharpで描画しICOへ格納し、新規依存を追加しない。

ブラウザーfaviconの変更に限定し、既存PWA manifest・アプリ用画像・保有データ・認証は変更しない。採用SVG/ICOはリポジトリで管理し、比較案・Claude出力・一時描画scriptはscratchへ残す。本番反映は最終承認後。
