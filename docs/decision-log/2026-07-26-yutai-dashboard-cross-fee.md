# 2026-07-26 優待ダッシュボードの日興クロス手数料 概算表示

## 背景

- 簡易優待効率（[2026-07-18](./2026-07-18-yutai-dashboard-simple-efficiency.md)）の次段階として、「その日に買った場合、その銘柄のクロス取引にいくら手数料がかかるか」を一覧で見たい。
- 対象は一覧テーブルの「簡易効率」列。効率チップ（1段目）の下に 2段目として手数料を出す。
- ベースは日興（SMBC日興証券）。買い方は制度信用買い→現引きに固定するという運用前提が会話で固まった。

## 今回決めたこと

結論: 「約定金額 × 年率 × 保有日数 ÷ 365」で、買い方金利＋売り方貸株料の概算を出し、簡易効率セルの 2段目に表示する。

- **買い**: 制度信用買い → 現引き（固定）。日興は信用委託手数料・現引き手数料ともに 0 円のため、コストは制度信用の買方金利のみ。
- **売り**: 一般信用売建の「対象銘柄」なら在庫状況によらず一般で計算する。**在庫0・取引停止など今すぐ売れない状態でも一般前提**。一般の対象外の銘柄に限り、奥の手として制度信用売りで計算する（＝制度は基本使わない前提）。
- **保有日数**: 今日（JST）→ 権利付最終日（権利月の月末最終営業日の 2 営業日前）の暦日数。
- **率**: `app/tools/_shared/yutai-cross-fee.ts` の定数 `NIKKO_CROSS_FEE_RATES` に集約する。2026-07 時点の日興公式値:
  - 制度信用 買方金利: 年 2.54%
  - 制度信用 貸株料: 年 1.15%
  - 一般信用 貸株料: 年 1.90%
- **逆日歩**: 予測不可のため金額には含めない。制度信用売りで計算したときのみ「＋逆日歩（別途）」を注記する。
- **表示**: 2段目に `手数料 ≈¥XXX`。内訳（買方金利・貸株料・約定金額・保有日数・権利付最終日・逆日歩注記）は title ツールチップ。制度買い不可なら `買建不可`、一般対象外かつ制度売り不可なら `売建不可`。

## 判断理由

- **売りは一般優先・制度は奥の手**: 一般信用売りは逆日歩が発生しないため、優待クロスの実務上の基本。制度信用売りは逆日歩リスクがあり、コストが読めないので奥の手扱いにするというユーザーの運用前提に合わせた。
- **一般対象なら在庫0でも一般で計算**: 在庫は日々変動し回復もし得る。「その銘柄をクロスするならいくらか」という計画値としては、今の在庫有無ではなく一般対象か否かで区分を決めるほうが実態に近い。データ上の判定は `available_shares !== null`（在庫枠を管理している）または `general_short` または 取引停止中を一般対象とする（`isNikkoGeneralTarget`）。`general_short` は在庫連動で false に倒れるため単独では使わない。
- **買いを制度信用買い→現引きに固定**: 日興ダイレクトコースでは信用委託手数料が 0 円で、現引き手数料も無料のため、現物買いより買い側コストを抑えられる。金利のみが残コストになる。
- **権利付最終日は近似**: 候補データは権利月（1〜12）しか持たず、正確な権利確定日を持たない。大半が月末締めのため「月末最終営業日の 2 営業日前」で近似し、15 日・20 日締め等の非月末銘柄はズレを許容（対象外として捨てる）。既存の `data-loader.ts` の権利付最終日ロジックを `app/tools/_shared/yutai-kenri-date.ts` に切り出して再利用し、権利月ごとの「今日→次回権利付最終日」の暦日数を算出する。
- **率は定数集約**: 金利・貸株料は改定が多い（2026 年に複数回改定）。1 か所（`NIKKO_CROSS_FEE_RATES`）を直せば済むようにし、次回改定への追従コストを下げる。

## 影響範囲

- `app/tools/_shared/yutai-cross-fee.ts`（新規: 率定数・売り建て区分の解決・手数料計算）
- `app/tools/_shared/yutai-kenri-date.ts`（新規: 権利付最終日ロジックの共有化＋暦日数算出）
- `app/tools/_shared/yutai-credit.ts`（追加: `isNikkoGeneralTarget`）
- `app/tools/yutai-candidates/data-loader.ts`（権利付最終日ロジックを共有モジュールへ移動）
- `app/tools/yutai-dashboard/page.tsx`（権利月別の権利付最終日情報を算出し props で渡す）
- `app/tools/yutai-dashboard/ToolClient.tsx`（簡易効率セルを 2段構成にし、2段目に手数料を描画）
- 互換性: 既存の簡易効率表示・並び順は変更なし。手数料は候補行かつ株価・必要株数・日興データが揃うときだけ表示する追加要素。

## 残課題

- 率は変動する。実運用前に日興口座の現行値と突き合わせ、必要なら `NIKKO_CROSS_FEE_RATES` を更新する。
- 一般信用 貸株料は短期／長期（無期限）などの区分で異なり得るが、現状は 1 本の率で概算している。
- 権利付最終日は月末締め前提の近似。非月末締め銘柄の日数はズレる。
- 保有日数は「今日→権利付最終日」の暦日ベース。現引き・現渡しの受渡日基準の厳密な金利日数計算までは踏み込んでいない。
- 逆日歩は金額に含めない（制度信用売り時に注記のみ）。
