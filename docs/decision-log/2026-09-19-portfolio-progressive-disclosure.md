# Portfolio初期表示の情報密度整理

利用者の承認に基づき、UI-4 / V2 Phase 6の読み取りUIを整理する。データ・方針の正本・完成条件は変更しない。

- 主導線は意思決定・保有一覧・履歴。口座・取込、方針、DB確認は詳細メニューから引き続き閲覧可能。
- 企業グループ集中は保有一覧の展開詳細へ移し、ページタイトルより前に出さない。
- active policyの版・名称・冒頭と判断状態/鮮度を初期表示する。全文・原則・ルールはネイティブdetailsで展開する。
- reviewの長文は冒頭抜粋であることを明記し、全文も保持。新しいAI要約は生成しない。
- 推薦は対象・順位・種別・金額状態を、Actionは名称・状態・期限を初期表示。根拠/条件は展開可能。
- 振り返りも末尾から展開可能。警告・未取得の表示は隠さず、件数やデータは削除しない。

画面整理は表示不具合修正PR #668の後に適用する。
