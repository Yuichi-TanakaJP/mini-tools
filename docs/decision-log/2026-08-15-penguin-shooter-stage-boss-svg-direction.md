# 2026-08-15 ペンギンシューター ステージボスSVG方針

## 結論

- 10大ステージ化に向けて、ステージボス10体を個別SVGとして用意する。
- Stage 1〜9は「中央コア、装甲、武装モジュール」を共有する機械系デザインとする。
- Stage 10のラスボスだけは同系統の上位機体にせず、生物的な次元裂け目として別系統にする。
- SVGは表示素材に限定し、当たり判定、攻撃、HP、アニメーションはゲームコード側で管理する。

## 背景

既存のボスデータには個別の `visual` が定義されているが、現在の描画は中間ボス共通とステージボス共通のCSS図形になっている。ステージごとの外観差を明確にしながら、小画面での輪郭、拡縮、発光演出を維持できる素材形式が必要になった。

## 決めたこと

- 素材は `public/games/penguin-shooter/bosses/` に配置する。
- 全素材の `viewBox` を `0 0 240 180` に統一する。
- Stage 1〜9は中央付近にコアを置き、共通の当たり判定へ合わせやすくする。
- ラスボスは操縦席、左右砲台、対称的な宇宙船形状を使わない。
- ラスボスは左右非対称の翼膜、縦長の眼、触手、浮遊結晶で「機体ではない存在」として表現する。
- 今回は素材作成までとし、ゲームへの組み込みと10ステージ化は後続変更に分ける。

## 理由

- CSS図形だけで10体を作り分けると、描画コードとスタイル定義が肥大化する。
- PNGの完成画像よりSVGの方が、画面密度に依存せず輪郭を保ち、部品単位の発光や揺れへ拡張しやすい。
- ラスボスだけ造形規則を崩すことで、最終戦へ到達したときの異質さを一目で伝えられる。

## 影響範囲

- `public/games/penguin-shooter/bosses/`
- 後続の `app/tools/penguin-shooter/stageData.ts`
- 後続の `app/tools/penguin-shooter/ToolClient.tsx`
