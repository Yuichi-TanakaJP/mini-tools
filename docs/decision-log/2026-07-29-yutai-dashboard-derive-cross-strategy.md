# 2026-07-29 優待ダッシュボードの戦略欄「長期優遇なし」自動導出

## 背景

- 優待ダッシュボードの一覧テーブル「クロス戦略」列は、メモ未登録の銘柄をすべて「未設定」と表示していた。
- クロス戦略（単発 / 連続 / 先行 / 1株放置）は、長期優待特典がある銘柄でだけ選択に意味がある。長期特典が無い銘柄は戦略判断が不要で、必然的に「長期優遇なし」になる。
- 「戦略を考えるべき銘柄」と「考える必要が無い銘柄」を仕分けたい、という運用上の要望が発端。

## 今回決めたこと

- メモが無い銘柄でも、公式条件（launch-display）に長期特典が無いと判定できた場合は「長期優遇なし」を自動導出して表示する。
- 自動導出値はクロス戦略フィルタの絞り込み対象にも含める（表示とフィルタで同一の実効値を使う）。
- 導出は表示・絞り込み専用で、メモの自動保存はしない。手動設定済みの値は常に優先し上書きしない。
- 次の場合は従来どおり「未設定」を残す:
  - 公式レコードが無い（＝長期特典の有無が不明）銘柄
  - 長期特典があるが戦略未トリアージの銘柄

## 判断理由

- 「長期特典なし ≡ 戦略不要 ≡ 長期優遇なし」というユーザーのモデルに沿う。特典ありの銘柄が「長期優遇なし」へ倒れることは無いため、戦略欄（ユーザーの意思）と公式事実の混線は起きない。
- 残る「未設定」が「特典ありだが戦略未決定」に絞られ、トリアージ対象の抽出として機能する。
- 公式レコードが無い場合まで「長期優遇なし」と断定すると、`getLongTermFlags(null)` が `benefit:false` を返す仕様上、不明を事実として誤表示しフィルタで取りこぼす。そのため「レコードあり かつ 長期特典なし」に限定した（既存の長/特チップと同じ `getLongTermFlags` 判定に揃える）。
- メモ自動生成案は、大量メモ生成・同期データ肥大・pick/pass トリアージ概念の崩れを招くため採らず、表示・絞り込み専用の実効値導出に留めた（恒久対応）。

## 影響範囲

- `app/tools/yutai-dashboard/cross-strategy.ts`
  - `getRowCrossType()` を純関数として実装（実効クロス戦略の導出。メモ優先、無ければ公式条件から導出）。単体テストは `__tests__/cross-strategy.test.ts`。
- `app/tools/yutai-dashboard/ToolClient.tsx`
  - `getRowCrossType()` を import し、クロス戦略フィルタ（`filteredRows`）と表示セル（`renderCrossTypeCell`）の両方で導出値を使用。
  - 導出値は手動値と区別できるよう控えめ表示（`cellMuted`）＋ツールチップ。手動値は従来どおりチップ。
- 仕込み月軸（`calendarRows`）は登録メモ限定のため対象外（現状維持）。
- 詳細パネルのクロス戦略は `selectedRow.memo` 存在時のみ表示で従来どおり（導出値は出さない）。
- 互換性: メモや保存データの形式は変更なし。表示・絞り込みのみの差分。
- **全月ビューでは自動導出が働かない**: `rowLaunchDisplayByKey` は全月表示時に空 Map で渡されるため、メモ無し行は常に「未設定」となり「長期優遇なし」フィルタにも掛からない。launch-display は権利月単位のデータで全月表示が per-month 公式条件を持たない仕様に沿ったもので、既存の長/特チップと同じ挙動。自動導出は対象月を選択したときだけ働く。

## 残課題

- 公式レコードはあるが `no_conditions` 等で条件を抽出できない銘柄は、現状「長期特典なし」と同じ扱い（既存の長/特チップと同挙動）。不明として更に切り分けるかは未検討。
